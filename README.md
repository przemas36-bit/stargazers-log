# stargazers-log

Dziennik repozytoriów oznaczonych gwiazdką.

## Opis
Aplikacja służy do śledzenia i archiwizowania repozytoriów, które zostały oznaczone gwiazdką w GitHubie.

## Funkcjonalności
- zapisanie listy ulubionych repozytoriów
- śledzenie zmian w czasie
- wyszukiwanie i filtrowanie
- łatwe eksportowanie danych

## Wymagania
- Node.js 20+
- Git
- Konto GitHub

## Instalacja
```bash
git clone https://github.com/przemas36-bit/stargazers-log.git
cd stargazers-log
npm install
